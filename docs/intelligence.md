# Browser intelligence: reference and implementation notes

Researched against Apple’s macOS 27 SDK and official documentation on 18 October 2026. Deployment remains macOS 26. There are no package dependencies or bundled model weights.

## Product behavior

The [Arc Max reference](https://resources.arc.net/hc/en-us/articles/19335160678679-Arc-Max-Boost-Your-Browsing-with-AI) specifies manual Tidy Tabs above six Today tabs, shorter titles when pinning tabs, reversible automatic download naming, and Shift-hover link previews with automatic hovering on certain sites. Browser calls saved sidebar rows **Pinned Tabs**. The separate favicon grid is **Essential Tabs**, uses **Add to Essential Tabs** / **Remove from Essential Tabs**, and is excluded from title tidying. Saved pages at the root and inside nested folders support manual naming directly in the tab row: Return saves the live field-editor text, Escape cancels, and focus loss saves once.

Temporary topic groups expand and collapse like saved folders, with indented child rows, drag targets, and session-persisted collapse state. Keyboard selection reveals its containing group. Existing lowercase or slug-like labels migrate to readable display titles. These groups belong to window sessions, not the saved-folder store. Tidying does not create permanent folders, load sleeping tabs, change saved descriptors, or mutate webpage document titles. The explicit **Pin as Folder** context action promotes a group into a durable pinned folder, saving all members together while keeping the group’s title, icon, order, and expansion state. Drag collapse is transient presentation state, so a crash cannot leave a previously open folder persisted as closed. It preserves every tab, validates model IDs against the current page URL/membership, keeps unassigned tabs accessible, and never closes pages when grouping or removing groups. An 18-tab batch includes existing topic labels so later batches can merge with earlier groups. Names and section metadata are small JSON fields in existing stores.

## Local model and resource decisions

- [SystemLanguageModel](https://developer.apple.com/documentation/foundationmodels/systemlanguagemodel) is Apple’s on-device model. `.default` is the public general-purpose entry point. macOS 27 exposes `variant` as a read-only property; this SDK has no public initializer that selects `coreAdvanced3`. Browser uses the installed system-selected model rather than guessing a different model or silently routing to Private Cloud Compute.
- Check `availability` at use time and show the reason in settings. Unsupported Macs, disabled Apple Intelligence, and models that are still preparing leave ordinary browsing and manual naming working. There is no cloud fallback or separate download UI.
- [Guided generation](https://developer.apple.com/documentation/foundationmodels/generating-swift-data-structures-with-guided-generation) provides typed structures instead of fragile JSON parsing. Topic icons use a small local symbol mapping, so the model only generates names and memberships. Output IDs still need application validation: a valid structure alone does not prove semantic correctness.
- [Generation options](https://developer.apple.com/documentation/foundationmodels/generationoptions) use greedy decoding and bounded response budgets. Fresh sessions avoid transcript growth; prompts carry bounded title/path snippets or at most 3,500 characters of page text. URL user info, query parameters and fragments are omitted from organizing/naming prompts.
- A single asynchronous inference gate bounds concurrency. Interactive previews and tidying take priority over queued background naming. Cancelled waiting jobs leave the queue immediately, and completed results are checked for cancellation and stale page state before application. Sessions and their transcripts are released after each request. Strong intent (hovering Tidy Tabs, loading a saved page, starting a download, or fetching a preview) prewarms a fresh session for up to 30 seconds. There is no startup warm-up, polling, page-wide text extraction for names, or inference during dragging. A bounded 64-entry memory cache avoids regenerating identical names.
- Apple’s [safety guidance](https://developer.apple.com/documentation/foundationmodels/improving-the-safety-of-generative-model-output) treats webpage content as untrusted input. These sessions have no tools or side effects. Instructions distinguish data from commands; the app validates names, filenames and identifiers outside the model. Refusals and generation failures preserve original names/order rather than manufacturing a result.

## Link previews and download safety

Previews install an isolated-world, event-driven hover handler. Disabled previews register no input listeners. Hover work is cancelled on leaving, scrolling, clicking, navigation, or closing the card. A preview fetch uses an ephemeral URL session without cookie storage, credentials or disk cache, checks redirects and MIME/status, caps the HTML buffer at 128 KiB, and applies timeouts. It does not run scripts or fetch subresources. Local/non-web/numeric-IP links are excluded. HTML scripts, styles and navigation are removed before generation. Sixteen results are cached in memory for five minutes; fetched text and summaries are not persisted.

Download naming runs only after successful completion and quarantine tagging. It uses metadata, never reads the downloaded file, preserves the original extension (including common compound archives), strips path separators and control characters, and moves within the Downloads directory. FileManager refuses overwrites even if a collision occurs after the name check. Undo uses the same collision-safe path. Turning off the feature or clearing a pending item prevents a late suggestion from changing its file.

## Validation

A live Foundation Models probe on this Mac reported **AFM 3 Core**, available. The original eight-page probe took approximately 7.5 seconds. The optimized seven-page probe grouped Rust, WW2, and gardening pages correctly in approximately 2.75–3.10 seconds; separate warm title requests took 0.84–1.63 seconds and a factual preview took 1.67–2.12 seconds. These are uncached model requests, not cache-hit timings. Cold models, system contention, network fetches, and larger batches can exceed two seconds. Title generation returned **Rust Ownership** from a verbose title containing `(24)`. A supplied Rust ownership excerpt generated a factual preview. “5-second previews” names the reference interaction, not a guaranteed deadline; both network and system inference latency vary.

Targeted tests cover backward-compatible session decoding, lazy restoration of sections, no lost/duplicated tabs under invalid assignments, eligibility of temporary tabs, group removal with newly opened tabs, durable manual names, original-title restoration, haptic feedback only on actual moves, URL/markup filtering, filename containment/extension preservation, and a real WebKit download renamed and undone around collisions while retaining quarantine metadata. Automatic model output is evaluated separately from deterministic persistence and file-safety tests.

## Loading presentation

Pending saved titles and download names shimmer locally without changing the rest of the sidebar. Link previews show a shimmer skeleton while fetching and summarizing. The Tidy Tabs label keeps its divider static when idle and animates it as a sine wave traveling left to right with stationary end segments while categorizing; clicking the label again cancels. Animations respect Reduce Motion and stop when their individual tasks complete or cancel.
